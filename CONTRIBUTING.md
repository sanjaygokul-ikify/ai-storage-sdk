# Contributing Guidelines

Thank you for considering contributing to the AI-Powered Storage SDK project.

## PR Workflow
1. Fork the repository: `git fork https://github.com/username/ai-storage-sdk.git`
2. Create a new branch: `git checkout -b feature/new-feature`
3. Make changes and commit: `git commit -m 'New feature'`
4. Push changes: `git push origin feature/new-feature`
5. Create a pull request

## Commit Standards
* Use descriptive commit messages
* Follow the conventional commit message format

## Code Style Rules
* Use PEP 8 conventions for Python code
